# DEMOLAY CUP — Design Direction

## Colors
- Background: `#0D1117` (deep dark)
- Surface: `#161B22` (cards)
- Surface elevated: `#21262D`
- Primary: `#F59E0B` (gold/amber — matches logo)
- Primary dark: `#D97706`
- Text primary: `#FFFFFF`
- Text secondary: `#8B949E`
- Danger: `#EF4444`
- Success: `#22C55E`
- Border: `#30363D`

## Typography
- Font: Poppins (Google Fonts)
- Display: Poppins 700/900 uppercase
- Body: Poppins 400/500
- Stats: Poppins 700 tabular-nums

## Layout
- Mobile-first (primary use on phone)
- Max width: 480px centered on desktop, full-width on mobile
- Bottom navigation bar on mobile
- Sticky header with tournament name

## Style
- Dark theme only
- Gold accents on borders, highlights, position badges
- Tables with alternating row shading
- Bracket with connecting lines
- Cards with subtle gold border-left for emphasis
- No border-radius overkill — 6–8px max
